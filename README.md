# 🔎 LOST & FOUND – Campus Recovery Platform

A full-stack campus Lost & Found management system designed to help students report lost and found items, discover possible matches, request item recovery, verify ownership, receive notifications, and raise complaints.

The backend is developed using **Java and Spring Boot** and exposes REST APIs that can be consumed by a React frontend.

---

## 📌 Project Overview

In a college campus, students frequently lose personal belongings such as:

- Wallets
- ID cards
- Mobile phones
- Earphones
- Laptops
- Books
- Bags
- Water bottles
- Other personal items

Traditional lost-and-found systems usually depend on notice boards, WhatsApp groups, or manual communication.

This project provides a centralized platform where users can:

1. Register and log in securely.
2. Report lost items.
3. Report found items.
4. Search and filter reported items.
5. Automatically find possible matches between lost and found items.
6. Send recovery requests.
7. Accept/reject recovery requests.
8. Track the recovery process.
9. Receive notifications.
10. Raise complaints.
11. Allow administrators to review and resolve complaints.

---

# 🎯 Main Objectives

- Build a centralized campus Lost & Found platform.
- Reduce manual communication between students.
- Provide meaningful item matching using deterministic business logic.
- Implement a secure recovery workflow.
